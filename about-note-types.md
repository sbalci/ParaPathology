# About Note Types

Tolaria uses note types to describe a page's role. A type helps distinguish a subject overview from a specific disease, method, tool, or source.

| Type | What it means |
| --- | --- |
| Topic | A subject overview that gathers related notes. |
| Reference | A curated list of books, sites, repositories, or other resources. |
| Tool | A page about one named program or application. |
| Clipping | A captured outside source; public digests are collected in [[Clippings]]. |
| Lecture | Teaching material, often for medical school. |
| Note | Original explanatory writing that does not fit a more specific type. |
| Disease | A specific diagnostic entity or reaction pattern. |
| Concept | One mechanism, principle, or idea. |
| Technique | A method, assay, stain, or computational procedure. |
| Framework | A theory, classification system, or analytical lens. |

Notes may also link across subjects. Browse the [[Browse by Subject]] index when the topic matters more than the note type.
