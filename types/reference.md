# Reference

A curated catalog, link-list, or resource note that points at *many* things — e.g. `github-repositories`, `web-pages`, `books`, `antibody-list`, `courses-and-moocs`. Content is mostly pointers outward rather than original prose. For a note about a *single* program, use `Tool` instead. Status is derived from resource-link count, not word count.
