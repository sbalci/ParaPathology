# Tool

A single piece of software, application, or online utility — e.g. `QuPath`, `orange`, `jasp`, `vosviewer`, `cytomine`, `endnote`. Distinct from `Reference` (which catalogs *many* resources) and from a prose `Note`: a Tool note is about one nameable program. Status for Tool/Reference notes is derived from resource-link count, not word count, so a short-but-complete pointer note is not mislabeled a stub.
