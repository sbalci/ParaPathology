# Theories and Frameworks

Theoretical lenses for understanding pathology as a practice: cognitive and perceptual accounts of diagnosis, systems views of the laboratory, and frameworks for how AI integrates into diagnostic work. These notes step back from case-level knowledge to ask how pathologists actually see, decide, classify, and organize.
